## 01. Что такое холст / worksheet

001. Worksheet (рабочий лист) в Mathcad — это одновременно документ, калькулятор и отчёт.
002. Пользователь пишет «как на бумаге»: формулы выглядят как в учебнике — дробь с чертой, степень сверху, корень с выносом.
003. Холст (canvas) — бесконечная в длину область, разбитая на страницы для печати.
004. В Prime (в отличие от Mathcad 15 с белым фоном) холст по умолчанию выглядит как инженерная миллиметровка: светло-серая сетка на белом.
005. Всё содержимое состоит из регионов (regions) — прямоугольных объектов с данными.
006. Пустой клик по холсту ставит точку вставки: синее перекрестие (blue crosshair).
007. Набор с клавиатуры в пустом месте сразу создаёт math-регион; это режим по умолчанию (math is default insertion mode).
008. Текст вставляется только явной командой: Text Box (Ctrl+T) или Text Block (Ctrl+Shift+T).
009. Каждый открытый worksheet живёт в своей вкладке под Ribbon (Open Worksheets Bar).
010. Ресурсы ограничивают только число вкладок; пересчёт идёт по каждому листу отдельно.
011. Файл листа: `.mcdx` (Prime), шаблон: `.mctx`; старые `.mcd` (Mathcad 15) конвертируются.
012. Лист хранит: регионы + их геометрию + стили + установки документа (единицы, формат результата, допуски CTOL).
013. Печать идёт постранично; экранный холст длиннее печатного за счёт Draft-страницы (см. раздел 03).
014. Масштаб (zoom slider) меняет только вид, не пересчёт.
015. Автопересчёт: любое изменение math-региона мгновенно пересчитывает зависимые регионы ниже/правее.
016. Состояние расчёта видно в Status Bar цветным кружком: зелёный — ок, жёлтый — идёт расчёт, красный — ошибка.
017. Поиск/замена (Find and Replace) ищет по строкам в Text-регионах и по именам/индексам в Math-регионах.
018. Гиперссылки могут вести на регион внутри листа или наружу.
019. Вставка изображения (Image region) — статична, не участвует в расчёте, поддерживает прозрачность.
020. Компоненты (Excel, скрипты) живут в своих регионах, но выглядят как таблицы/кнопки на холсте.

## 02. Визуальный каркас окна Prime

021. Сверху вниз окно Prime устроено так:
022. Строка заголовка + Quick Access Toolbar (QAT): сохранить, отменить/вернуть, печать.
023. Ribbon (лента): вкладки Math, Matrices/Tables, Plots, Math Formatting, Text Formatting, Calculation, Document.
024. Подсказки (tooltip) на каждой кнопке Ribbon объясняют действие и показывают хоткей.
025. Open Worksheets Bar: вкладки `Untitled:1`, `Имя.mcdx`; закрытие вкладки — Ctrl+W.
026. Рабочая область: слева — белая страница с сеткой, справа (в Draft view) — серая черновая полоса за пунктирной линией.
027. Status Bar снизу: номер страницы (клик + ввод числа = переход), кружок состояния, Find, Zoom Slider, кнопки Page/Draft View.
028. Контекстное меню (правый клик по пустому месту): вставить регион, вставить разрыв страницы, свойства страницы.
029. Контекстное меню региона: вырезать/копировать/вставить, отключить (Disable), защитить (Protect), формат результата.
030. Шрифт текста по умолчанию: Tahoma; шрифт математики по умолчанию: Mathcad UniMath Prime, 11 pt, чёрный.
031. Активный регион обведён пунктирным прямоугольником; выделенный (для форматирования) — тёмно-серым.
032. Активный оператор внутри формулы подсвечен синим; операнды при этом группируются.
033. Плейсхолдеры (пустые места) — маленькие чёрные прямоугольники; при вставке оператора новые плейсхолдеры подсвечиваются синим.
034. Курсор математики — синяя вертикальная черта `|`; точка вставки в пустом листе — синее перекрестие `+`.
035. Неявное умножение показывает оператор масштабирования (маленькая точка/пробел), видимый только при клике в регион.
036. Сетка (grid): Standard (крупная) или Fine (мелкая); переключатель Document → Show Grid / Grid Size.
037. Уменьшение сетки на плотном листе вызывает наложение регионов; лечится Document → Separate Regions → Vertically/Horizontally.
038. Поля страницы, header/footer видны только в Page View; в Draft View их нет.
039. Header/footer: двойной клик выше/ниже сетки или Document → Headers and Footers → Header/Footer.
040. В header/footer можно вставить имя файла, дату сохранения, логотип, номер страницы.

## 03. Сетка, виды, поля, разрывы

041. Сетка — это визуальная привязка, а не таблица: регионы можно ставить в любую клетку.
042. Выравнивание «короткое описание слева — формула в центре — ссылка справа» делается вручную расстановкой регионов по одной горизонтали.
043. Prime не имеет колонок-контейнеров из коробки; запрос на columns/region-layout висит в Community как feature request.
044. Обходной путь под колонки: math-in-text (текст с встроенной математикой) — единый перемещаемый блок.
045. Минус обходного пути (по отзывам): math-in-text труднее править, он хрупкий при росте формул.
046. Page View: вид как на печати; поля, header/footer видны; регионы на draft-странице скрыты, но участвуют в расчёте.
047. Draft View: справа от вертикального пунктира — черновая страница; удобна для скрытых вводов/выводов во внешние файлы.
048. Кнопка «Switch to Draft View» появляется справа, если на черновике есть регионы.
049. Отступы между регионами: Enter добавляет пустую строку-отступ; Delete/Backspace между регионами убирает лишнее место.
050. Text Block при росте/усадке сдвигает регионы ниже вверх/вниз; Text Box и Math — свободно перекрываются.
051. Page Break вставляется вручную, чтобы формула/график не разрывалась между печатными страницами.
052. Document → Add/Remove Empty Space — сжать/раздуть вертикальные зазоры.
053. Show Grid off даёт «чистый» вид для скриншотов и PDF через File → Save As → PDF.
054. Fine grid рекомендуют включать в начале листа, до расстановки регионов, иначе будут наложения.
055. Наложенные регионы выглядят как «слипшийся» текст; разделяются командой Separate Regions.
056. Печатные поля настраиваются в Document → Page → Margins; единицы — дюймы/мм по локали.
057. Ориентация/размер бумаги — там же; формулы не переносятся автоматически, длинные выражения уходят за поле.
058. Для длинных выражений используют equation break operators: Ctrl+Shift+- (вычитание), Ctrl+Shift+* (умножение), Ctrl+Shift+/ (inline-деление).
059. Переключение обычный/разрывной оператор — повтор того же хоткея.
060. Разрыв строки в регионе без разрыва смысла — Ctrl+Shift+Enter (новая строка) против Enter (выход из региона).

## 04. Регионы: таксономия

061. Math Region — формула/определение/вычисление; участвует в расчёте; синяя рамка при активации.
062. Text Box — короткий текст, свободно перемещается, может перекрывать других; Ctrl+T.
063. Text Block — абзац на всю ширину страницы, не перекрывается, толкает соседей; Ctrl+Shift+T.
064. XY Plot (2D Plot) — декартов график; изменяемый размер за уголок.
065. Polar Plot — полярный график.
066. 3D Plot — поверхность/контур/точки/стержни; вращается мышью.
067. Chart Component — «публикационный» график: заголовки, легенды, две оси Y, сетки, логарифм, форматирование шрифтов.
068. Image — картинка (PNG/JPG/BMP с прозрачностью); не считается.
069. Table (Matrices/Tables → Insert Table, до 10×10) — колонки становятся векторами `ИмяСтолбца`; заголовок = имя + единицы.
070. Matrix — math-регион с сеткой `[]`; ввод через `,` (столбец) и `;` / Shift+Enter (строка).
071. Area — складной контейнер для группы регионов; сворачивается в одну строку-заголовок.
072. Solve Block — связка Given/Find/Minerr/Odesolve с ограничениями; визуально — вертикальная группа math-регионов.
073. Program (Programming) — вертикальная черта с `|`, операторы If/Otherwise/While/For/Return/Break/Continue; локальное `←` (стрелка, `{`).
074. Symbolics — math-регион со стрелкой `→` и ключевыми словами (simplify, solve, float и т.п.).
075. Excel Component — встроенная таблица Excel; двусторонний обмен.
076. Scripted Component — пользовательский компонент (редко).
077. Header/Footer — служебные текстовые области вне сетки.
078. Global Definition — регион с `≡` (тройное равно), виден всегда, считается до всего листа.
079. Каждый регион имеет: геометрию (x, y, w, h), флаг disable, флаг protect/hide, формат результата (для math).
080. Регион можно: move (drag), cut/copy/paste (Ctrl+X/C/V), resize (плоты/картинки за ручки), disable, delete.

## 05. Жизненный цикл региона

081. Создание math: клик по пустому месту → синее перекрестие → набор `3/4+5^2=` → регион с результатом.
082. Создание text box: Ctrl+T → прямоугольник с текстовым курсором → набор → клик мимо завершает.
083. Создание text block: Ctrl+Shift+T вверху листа → полоса на всю ширину → заголовок → Center Text.
084. Создание math-in-text: клик внутрь текста → Math tab → Math (или Ctrl+Shift+M) → пустой плейсхолдер → формула.
085. Активация (activate): одиночный клик внутрь региона → пунктирная рамка + синий курсор; результат пересчитывается.
086. Выделение (select): drag через регион → тёмно-серая заливка; нужно для форматирования, копирования целиком.
087. Перемещение: drag за рамку (не за содержимое); text block тянет соседей; остальные плывут свободно.
088. Копирование между листами: Ctrl+C в одном → клик по пустому месту в другом → Ctrl+V; имена/единицы копируются.
089. Изменение размера: только plot/image/table — белые квадратные ручки по краям; math/text тянутся сами по содержимому.
090. Удаление: выделить → Delete/Backspace; удаление определения не удаляет зависимые — они краснеют с ошибкой «undefined».
091. Отмена/возврат: QAT Undo/Redo или Ctrl+Z/Y; отмена двигает и геометрию, и содержимое.
092. Disable: правый клик → Disable Evaluation; регион сереет, из расчёта исключается, график не перестраивается.
093. Enable обратно — тот же пункт; Areas можно disable целиком одним кликом.
094. Protect/Lock/Hide: через Area или Document → Protect; скрытые регионы считаются, но не печатаются.
095. Перетаскивание внутрь Area запрещено drag&drop — только Cut → клик внутрь Area → Paste.
096. Вставка строки внутри таблицы/матрицы: Shift+Space (столбец), Shift+Enter (строка).
097. Разделение наложенных: выделить оба → Document → Separate Regions → Vertically/Horizontally.
098. Навигация между регионами: Tab/Shift+Tab (след./пред. плейсхолдер), стрелки выходят из региона в соседний.
099. Enter внутри math — выход из региона вниз; Enter внутри text box — новая строка абзаца (или Shift+Enter внутри бокса).
100. Ctrl+Enter — toggle region selection (выделить весь регион, не выходя).

## 06. Math-регион: отображение

101. Формула рисуется «как в книге»: горизонтальная дробная черта, верхний индекс, корень с крышей, интеграл с пределами.
102. Встроенные (built-up) дроби растут по высоте вместе с числителем/знаменателем.
103. Степень поднимается и уменьшается кеглем; вложенные степени лесенкой вправо-вверх.
104. Нижние индексы: literal subscript (Ctrl+-) — часть имени (`x.1`); array index (`x[1`) — обращение к элементу.
105. Греческие буквы: набор латиницы + Ctrl+G (`a` → `α`); `π` — Shift+P или `p` + Ctrl+G.
106. Операторы сравнения толстые: `=` (вычисление) тонкое, `Ctrl+=` (логическое `=`, thick equals) толстое.
107. Определение `:=` рисуется как двоеточие-равно; набирается `:` (colon).
108. Глобальное `≡` — Ctrl+Shift+~; символьное `→` — Ctrl+. или кнопка Symbolics.
109. Умножение явное: `*` (звёздочка-точка) или `×`; неявное: пробел/ничего → точка-масштабатор (почти невидима).
110. Деление: `/` — «этажная» дробь с чертой; Ctrl+Shift+/ — inline-деление `／` (солидус) для экономии места.
111. Корень: `\` — квадратный; Ctrl+\ — n-й корень с плейсхолдером степени.
112. Модуль/детерминант: `|` — вертикальные черты растут по содержимому.
113. Интеграл: Ctrl+Shift+I — знак с 4 плейсхолдерами (низ, верх, подынтегральное, переменная).
114. Производная: `Ctrl+Shift+D` или `?'` — Лейбниц `d/dx`; частная — аналогично с `∂`.
115. Сумма/произведение: Ctrl+Shift+S (Σ), Ctrl+Shift+P (∏) — с пределами снизу/сверху и телом справа.
116. Скобки растут автоматически: `()`, `[]`, `{}` тянутся по высоте содержимого.
117. Функции пишутся прямым шрифтом (`sin`, `cos`), переменные — курсивом; метка Label (Variable/Unit/Constant/Function) влияет на смысл.
118. Единицы — синим жирным (`m`, `s`, `N`); конфликт имён «m = метр vs m = переменная» решается Label.
119. Результат после `=` — обычная математика, но нередактируемая (result is locked); правка результата невозможна.
120. Длинный результат обрезается по ширине региона с прокруткой; формат числа задаётся Result Format.

## 07. Math-редактор: курсор, плейсхолдеры, группировка

121. Синее перекрестие в пустоте = «печатай — появится math-регион».
122. Синяя вертикальная черта внутри = текстовый курсор математики; мигает, двигается стрелками.
123. Чёрный плейсхолдер `■` = «сюда нужно что-то вписать»; синий плейсхолдер = только что созданный, ждёт ввода.
124. Tab / Shift+Tab прыгают по плейсхолдерам внутри оператора (числитель → знаменатель → बाहर).
125. Home/End — в начало/конец выражения; Ctrl+стрелки — через целый терм.
126. Spacebar — главный инструмент: расширяет выделение (группировку) на один терм по правилам предшествования.
127. Повторные Spacebar берут всё больше: `a+b*c` → `c` → `b*c` → `a+b*c`.
128. Направление группировки задаётся положением курсора: слева от терма vs справа + Shift+стрелки.
129. Shift+стрелка влево/вправо — расширить группу на один терм влево/вправо от курсора.
130. Сгруппированное — как в невидимых скобках: к нему можно применить оператор целиком.
131. Пример: выделить `19+52`, набрать `\` → корень накроет всю группу, а не одно число.
132. Пример: курсор слева от `52`, набрать `/` → `52` станет знаменателем; курсор справа от группы + `/` → группа станет числителем.
133. Замена оператора: клик по оператору (синеет + группирует операнды) → набор нового (`+` → `\` + Enter).
134. Удаление скобок: клик по одной скобке → Delete/Backspace → обе парные исчезают сразу.
135. Операнды — тоже группы: при замене/удалении оператора группы сохраняются целыми.
136. Drag-выделение мышью через термы — альтернатива Spacebar; подсвечивает синим.
137. Копипаст группы: выделить → Ctrl+C → клик в другой регион → Ctrl+V; форматирование сохраняется.
138. Enter выводит курсор из региона; результат тут же пересчитывается (авто-recalc).
139. Вложенность: стрелка вверх/вниз входит/выходит из степени/дроби/индекса; Ctrl+стрелка прыгает через уровень.
140. Подсказка новичкам: позиция курсора решает, что станет числителем/знаменателем/степенью — сначала двигай курсор, потом жми оператор.

## 08. Операторы определения и вычисления

141. `:=` Definition (двоеточие `:`) — присвоить: `x := 5`, `f(x) := sin(x)`, `A := [1,2;3,4]`.
142. `=` Evaluation (равно) — посчитать и показать: `x =` → `5`; `f(2) =` → число/матрица/ошибка.
143. Комбо `x := 5 =` — определить и тут же показать (inline evaluation): удобно, но в Solve Block иногда ломает сходимость (баг Prime 10).
144. Опытные избегают inline внутри guess-значений Solve Block: сначала регион-определение, потом отдельный регион-показ.
145. `≡` Global Definition (Ctrl+Shift+~) — видно из любого места листа, считается до всего; для констант проекта.
146. `→` Symbolic Evaluation (Symbolics → `→`) — символьный ответ: упростить, решить, разложить.
147. Модификаторы символьки: `simplify`, `solve`, `float,n`, `expand`, `factor`, `assume` — через запятую над стрелкой или Shift+Enter построчно.
148. Чейнинг `→ →` — последовательные символьные шаги; порядок ключевых слов влияет на ответ.
149. `Ctrl+=` Equal To (толстое равно) — логическое сравнение для программ и ограничений Given: `x Ctrl+= 5`.
150. `≠ ≤ ≥` — Ctrl+J? Нет: `<` + `>` дают `≠`; `Ctrl+9` даёт `≤`; `Ctrl+0` даёт `≥` (по шпаргалке Prime).
151. Локальное присваивание в программах: `←` (`{`) — живёт только внутри программы.
152. Диапазон (range): `1..10` (набрать `1;10`? В Prime — `..`); используется в циклах и векторизации.
153. Векторизация: стрелка над выражением (Vectorize) — поэлементная операция над массивом.
154. Нижний индекс массива: `[` — `x[1`; верхний: Ctrl+6 — степень; literal: Ctrl+- — часть имени.
155. Единицы при определении: `L := 5 m`; при вычислении Prime сам приводит к базовым СИ внутри.
156. Функция с единицами: `f(x) := ...`; вызов `f(3 m) =` — проверка размерностей автоматическая.
157. Системные переменные: `CTOL` (допуск сходимости, default 1e-3), `ORIGIN` (начало индекса, 0/1).
158. Переопределение ниже по листу затеняет верхнее; выше — не видит нижнего (кроме global).
159. Имя с точкой `v.1` — одно имя, не «v точка 1»; цифра после точки — часть имени для вариантов.
160. Стиль Label: Variable / Unit / Constant / Function (Math tab → Style → Labels); неверный label ломает смысл (`m` как метр vs переменная).

## 09. Порядок вычислений и зависимости

161. Правило: сверху вниз, слева направо (top-to-bottom, left-to-right).
162. Регион видит только то, что определено выше и левее него (кроме global `≡`).
163. Использование до определения → красная ошибка «This variable is undefined».
164. Циклическая ссылка `a := b+1`, `b := a+1` → ошибка рекурсии.
165. Перемещение региона мышью меняет порядок вычисления! Бросил формулу выше — она стала «раньше».
166. Text Block толкает соседей и тем самым может изменить порядок — осторожно с длинными абзацами.
167. Draft-страница считается наравне с основной; скрытое там определение всё равно видно ниже.
168. Disabled-регион из цепочки выпадает: зависимые краснеют, как будто определения нет.
169. Area-disabled выключает всю группу одним кликом — удобно для ветвлений «вариант А/Б».
170. Solve Block считается как единое целое: guess сверху → Given → ограничения → Find/Minerr снизу.
171. График пересчитывается при изменении любой переменной в его выражениях.
172. Изменение формата результата (десятичные знаки) не пересчитывает, только перерисовывает.
173. Единицы внутри Solve Block чувствительны к масштабу: Па vs МПа и мм vs м меняют числа на порядки и ломают сходимость.
174. Лекарство: лучший guess, больший CTOL (напр. 1e-1 вместо 1e-3 ценой точности) или функция `root` вместо блока.
175. Символьный движок единиц не знает: считает `m`, `s` обычными буквами; опция «Units/Constants in symbolics» лишь сохраняет подпись, не смысл.
176. `deg`/`°` символька не понимает — переводи в радианы или переопредели `deg := π/180` до использования.
177. Неявное умножение `2π` без оператора Prime понимает как `2·π` (вставляет scaling dot), но `πθ` склеит в одно имя — нужен явный `*`.
178. Inline-деление `a/b*c` с неявным умножением парсится иначе, чем `a/b·c`; стандарт ISO 80000-1 запрещает солидус перед `×/÷`.
179. Рекомендация PTC Help: явно ставь `*` там, где хочешь умножить; не полагайся на невидимку.
180. Кружок в Status Bar — первый индикатор: красный — ищи красные регионы сверху вниз, чини первое красное.

## 10. Текст: Block vs Box, math-in-text

181. Text Box (Ctrl+T): плавающий ярлык; можно класть поверх графика, рядом с формулой; перекрытия разрешены.
182. Text Block (Ctrl+Shift+T): полноширинный абзац; перекрытия запрещены; раздвигает лист.
183. Внутри текста Enter — новый абзац; Shift+Enter — мягкий перенос внутри бокса.
184. Форматирование текста: Text Formatting tab → Font (face, size, B/I/U, цвет, highlight), Paragraph (bullets, indent, align), Styles (Title, Heading 1..3, Normal).
185. Свои стили: правый клик по оформленному → Create Style → Edit Style (имя); хранятся в листе/шаблоне `.mctx`.
186. Math-in-text: клик в текст → Math → Math (Ctrl+Shift+M) → плейсхолдер → `E:=m·c^2`; считается как обычный math-регион.
187. Копипаст math → text тоже работает: выделить группу в формуле → Ctrl+C → в текст → Ctrl+V.
188. Форматирование math-in-text: выделить регион → Math Formatting → Font (Wide Latin, цвет, highlight), Results (General/Engineering), Size, Remove Format.
189. Плюс math-in-text: единый блок «текст+формула» двигается/копируется целиком — эрзац колонок.
190. Минус: править тесно, операторы с плейсхолдерами раздувают строку, большие формулы лучше держать отдельно.
191. Поиск по тексту ищет и внутри math-in-text (имена, индексы, literal subscripts).
192. Гиперссылка в тексте: выделить → Insert Hyperlink → на регион/файл/URL.
193. Списки, отступы, межстрочные — только в тексте; в математике их нет.
194. Картинка в тексте не живёт — только отдельным Image-регионом рядом.
195. Заголовок листа по канону Task 6-1: Text Block сверху → Center → Title style → под ним Text Box с описанием данных.
196. Header/Footer — тоже текст, но вне сетки; туда же кладут Saved Date в формате mm/dd/yyyy.
197. Язык интерфейса переключается; формулы от языка не зависят (имена — латиница/греческий).
198. Шрифты текста — любые системные (Segoe Print, Comic Sans, Arial, Lexend для читаемости).
199. Highlight жёлтым + border региона — приём из блога PTC для акцента важных мест.
200. Для PDF: File → Save As → PDF; шрифты и прозрачность картинок сохраняются.

## 11. Графики: 2D, Polar, 3D, Chart

201. Создание XY Plot: Plots tab → Insert Plot → XY Plot → три плейсхолдера: y (слева), x (снизу), + легенда.
202. Пример: `y: sin(x)`, `x: 0..10` или вектор; несколько трасс через запятую: `sin(x), cos(x)`.
203. Оси: двойной клик → вкладки X-Axis/Y-Axis: диапазон (Limits), сетка (Grid), логарифм (Log Scale), ticks, Number Format.
204. Форматирование трассы: цвет, толщина, тип линии (solid/dashed), маркеры (o, +, x), легенда (Show Legend).
205. Изменение размера: drag за белые ручки; пропорции свободные; шрифт осей масштабируется отдельно.
206. Новая ось/трасса: клик по графику → `+` или Shift+Enter (новая строка-ось).
207. Polar Plot: `r(θ)`, угол в радианах (или переопределённый `deg`); сетка — концентрические круги.
208. 3D Plot: `z(x,y)` или матрица Z; виды Surface/Contour/Scatter/Bar; вращение — drag, зум — колесо.
209. Chart Component: самый «издательский» — Title, Axis Titles, Legends, Secondary Y, Gridlines, Log, шрифты/углы.
210. Данные для графика: функция, вектор, матрица-столбцы, таблица (имя столбца = вектор).
211. Таблица до 10×10: Matrices/Tables → Insert Table → drag размер → заголовки `Имя [единицы]` → столбцы сразу считаются.
212. Диапазонная переменная для оси: `x := 0,0.1..10`; шаг влияет на гладкость кривой.
213. Ошибка «no real value» на графике — функция ушла в комплекс; включи Im/Re или поправь область.
214. Перекрытие math поверх plot разрешено: можно положить Text Box-аннотацию прямо на кривую.
215. Disable plot-региона замораживает картинку при тяжёлых расчётах.
216. Копирование графика между листами тянет и данные-источники (имена должны существовать в новом листе).
217. Печать графиков: векторная чёткость в PDF; прозрачные PNG-оверлеи не мылятся.
218. Частая жалоба: график «рвётся» на разрыве страницы — лечится ручным Page Break до/после региона.
219. Для NyaMath-важно: Mathcad разделяет «формулу» и «график» на два региона; график ссылается на имена, а не хранит копию формулы.
220. Подпись осей с единицами пишется вручную (`x, m`); автоподстановку единиц график не делает.

## 12. Матрицы, таблицы, векторы

221. Создание матрицы: `A := [` → сетка плейсхолдеров → `,` добавляет столбец, `;`/Shift+Enter — строку.
222. Индексация: `A[0` (при ORIGIN=0) — первый элемент; `A[1,2` — строка/столбец.
223. ORIGIN — системная переменная (0 или 1); меняет все индексы листа сразу — опасно менять в середине проекта.
224. Векторизация (стрелка над выражением): `A·B` поэлементно; без неё — матричное умножение.
225. Операторы: транспонирование (`A^T`), детерминант (`|A|`), обратная (`A^-1`), скалярное/векторное.
226. Функции: `rows()`, `cols()`, `length()`, `last()`, `sort()`, `reverse()`, `augment()`, `stack()`, `submatrix()`.
227. Таблица (Table) vs Матрица (Matrix): таблица — ввод данных с именами столбцов; матрица — вычисляемый объект.
228. Заголовок столбца таблицы: `Имя` + `[единица]`; столбец сразу становится вектором `Имя` для формул и графиков.
229. Диапазоны (Range): `i := 0..9`; использование `A[i` в формуле с `=` даёт таблицу вывода (evaluation table).
230. Evaluation table: столбец входа + столбец выхода; форматируется как матрица результата.
231. Вставка/удаление строк/столбцов в существующей матрице: клик внутрь → Matrices/Tables → Insert/Delete Row/Column.
232. Отображение больших матриц: скролл внутри региона; печать обрезает по ширине страницы.
233. Копипаст из Excel: через Excel Component (живая связь) или plain paste (статичная матрица).
234. Ошибка «index out of bounds» — индекс вне `[ORIGIN .. rows-1]`; лечится проверкой ORIGIN.
235. Ошибка «must be square» — детерминант/обратная только для квадратных.
236. Для NyaMath: матрицы Mathcad — плотные, 0/1-база переключаемая; у нас фиксируем 0-базу и явно пишем в хинтах.
237. Визуально матрица — скобки `[ ]`, растущие по содержимому; запятые между столбцами почти невидимы.
238. Вектор-столбец печатается вертикально; вектор-строка — горизонтально с запятыми.
239. Единицы в матрице: либо у всей матрицы (`A := [...] m`), либо поэлементно — смешивать размерности в одном столбце нельзя.
240. Поиск по элементам массива идёт через Find по имени массива, не по значению ячейки.

## 13. Единицы измерения

241. Mathcad — размерный калькулятор: `3 m + 200 cm =` → `5 m` (сам приводит).
242. Ввод единицы: после числа пробел + `m`, `s`, `N`, `Pa`, `°C` и т.п.; подбирается из списка (Units dropdown).
243. Свои единицы: `myUnit := 1.5 m`; дальше `5 myUnit =` работает как обычно; живут только в своём листе (или шаблоне).
244. Кастомные метки: та же величина в двух единицах складывается (`2 in + 3 m`), а фунты + метры — ошибка размерности.
245. Label решает: `m` как Unit (метр, синий жирный) vs `m` как Variable (курсив) — переключатель Math → Style → Labels.
246. Константы (`c`, `g`, `π`) имеют фиксированные Label Constant; их переопределение — плохая практика.
247. Результат показывает единицы автоматически; смена единиц результата — клик по плейсхолдеру единиц справа от ответа.
248. Безразмерный ответ единиц не показывает; попытка приписать единицу — ошибка.
249. Температура: `°C`/`°F` аффинные — разность и абсолют различаются; Mathcad различает, новичков ловит.
250. Углы: радианы безразмерны; `deg` — единица; символька `deg` не знает (см. 175–176).
251. Внутри Solve Block единицы меняют внутренний масштаб (Па vs МПа) и ломают сходимость — см. раздел 09.
252. Таблицы хранят единицы в заголовке столбца; графики единицы не подставляют — подписывай вручную.
253. Формат результата с единицами: Engineering vs General; число знаков — Math Formatting → Results.
254. Проверка размерности — бесплатный детектор ошибок: «extremely high/low value» часто означает перепутанные мм/м.
255. Плотность/давление/энергия — все через базовые СИ внутри; отображение — в выбранных.
256. Скопированные между листами свои единицы копируются как определения — проверь конфликты имён.
257. В NyaMath-терминах: единицы Mathcad = mathjs units; `defunit` у нас = custom units Mathcad.
258. Визуально единица — синий жирный текст после числа; плейсхолдер единиц после `=` — пустой синий прямоугольник.
259. Удаление единицы из ответа: выделить единицу → Delete → число станет безразмерным (если размерность позволяет).
260. Ошибка «incompatible units» — красная, с подсказкой ожидаемой размерности.

## 14. Solve Block, символька, программирование

261. Solve Block (блок решения):_guess → `Given` → уравнения (`Ctrl+=`) + неравенства → `Find`/`Minerr`/`Odesolve`.
262. Guess: `x := 1` выше `Given`; плохой guess — главная причина «no solution / bad solve body».
263. `Given` — просто слово-маркер отдельным math-регионом; после него — ограничения.
264. Ограничения пишутся толстым равно `Ctrl+=`, не `:=` и не `=`! Новички ошибаются именно тут.
265. `Find(x,y)` возвращает вектор решений; `Minerr` — ближайшее при несовместных; `Odesolve` — для ОДУ.
266. CTOL — допуск (default 1e-3); больше = легче сходится, но грубее; меняется в Calculation tab.
267. `root(f(x), x, a, b)` — одномерный поиск без блока; два значения `a,b` — вилка (bracket), одно — старт.
268. `root` менее капризен к guess, чем блок; для простых уравнений preferred.
269. Символька: выделить выражение → Symbolics → `→` → ключевое слово (`solve`, `simplify`, `expand`, `factor`, `float`).
270. Ключевые слова можно набирать вручную над `→` через запятую; несколько — через Shift+Enter построчно.
271. Символька не знает единиц/констант как сущностей — только как буквы; `Units/Constants in symbolics` лишь сохраняет подпись.
272. Точный vs численный: символька отдаёт точное (`√2`), для числа добавь `float,n`.
273. Programming: вертикальная черта `|`; операторы вставляются кнопками: If/Otherwise/While/For/Return/Break/Continue/Otherwise If.
274. Локальное `←` (`{`): `y ← x+1`; обычное `:=` внутри программы — глобальное (не делай так).
275. Условие в If — с толстым `Ctrl+=`, логики `AND/OR/NOT` — Ctrl+Shift+&/@/!.
276. Цикл For: `for i ∈ 1..10`; While: `while x Ctrl+< 5`; строки добавляются кнопкой Add Line.
277. Функция-программа определяется как `f(x) :=` + программный блок справа; вызывается как обычная.
278. Рекурсия в программах разрешена, но без базы — красный stack overflow.
279. Отладка программ: временные `=` внутри запрещены; выноси промежуточное наружу или возвращай вектором.
280. Визуально программа — узкий столбик с вертикальной линией слева; каждая строка — отдельный math-ряд.

## 15. Форматирование и публикация

281. Два независимых форматирования: Math Formatting (формулы+результаты) и Text Formatting (текст).
282. Глобальное: клик по пустому холсту → смена шрифта/размера → применяется ко всем новым регионам; старые не трогает.
283. Локальное: выделить регион/кусок → смена → только ему.
284. Math Font: face (UniMath Prime default), Size (11 default), Color (black), Highlight (none/yellow), Remove Format (сброс).
285. Result Format: General / Decimal / Scientific / Engineering / Fraction; знаков: Number of decimals; Tolerance for zero.
286. Толстое vs тонкое равно различаются и смыслом, и начертанием — форматированием не меняются.
287. Text Font: Tahoma default; Size; B/I/U/Strike; Color; Highlight; Sub/Superscript.
288. Paragraph: Bullets/Numbering, Indent, Align (Left/Center/Right/Justify), Line Spacing.
289. Styles: Title, Heading 1–3, Normal; свои через Create Style; живут в листе/шаблоне.
290. Region Border: правый клик → Show Border — рамка для акцента; в печати видна, если включена.
291. Highlight жёлтым — для ключевых результатов (совет PTC-блога).
292. Headers/Footers: имя, автор, компания+лого, дата, номер страницы; обязательно для «взрослого» листа.
293. Grid: Standard/Fine/Off — решить в начале; середина проекта со сменой сетки = наложения.
294. Areas: Expanded (рамка видна, красиво) vs Collapsed (одна строка, скрывает мясо); Hide Border — невидимая рамка.
295. Page Breaks — против «разорванных» формул/графиков между страницами.
296. Templates `.mctx`: units + properties + header/footer + styles + заготовки (тексты, переменные, регионы).
297. Sanity check: дать лист коллеге — «стоит ли сам по себе?»; неочевидные переменные подписать Text Box.
298. PDF: File → Save As → PDF (предпочтительно, сохраняет шрифты/прозрачность); не печатай через виртуальный принтер.
299. Цвета для публикации: тёмный текст по светлому, один акцент (жёлтый highlight), графики Chart Component с легендами.
300. Единицы в ответах и подписи осей — признак «публикационной готовности» по PTC.

## 16. Areas, защита, отключение

301. Area: Insert → Area → заголовок + складная стрелка; внутрь — Cut/Paste регионов (drag внутрь запрещён!).
302. Внутри Area можно всё: определения, расчёты, графики, даже Solve Block и Excel.
303. Collapse/Expand — стрелкой в заголовке; свёрнутое показывает только заголовок + иконку.
304. Польза: навигация по длинному листу; печать только нужного; сокрытие «кухни».
305. Hide Border — рамка не печатается, но группировка работает.

## 18. Ошибки и диагностика

341. Красный текст = регион-ошибка; сообщение всплывает при клике (tooltip) и в строке состояния.
342. «This variable is undefined» — использование выше определения или опечатка в имени/Label.
343. «Incompatible units» — сложены метры с килограммами; проверь Label и единицы столбцов таблицы.
344. «Index out of bounds» — индекс вне `[ORIGIN, rows)`; проверь ORIGIN и размер.
345. «Must be square» — det/inverse неквадратной; «Must be real» — комплекс там, где ждут вещественное.
346. «No solution / bad solve body» — guess плох, inline `=` в guess, масштаб единиц, CTOL мал.
347. «Recursion» — циклические определения; разорви цепочку промежуточной переменной.
348. «Singular matrix» — детерминант ноль; система вырождена.
349. «Overflow / Tolerance» — числа вне диапазона; смени единицы (мм→м, Па→кПа) или формат.
350. Первое красное сверху — чини первым; нижние красные часто лишь следствие.
351. Кружок Status Bar: клик показывает число ошибок; двойной клик прыгает к первой.
352. Временное лечение: Disable подозрительной Area — если красное ушло, копай внутри неё.
353. Символьные ошибки («no symbolic result») — попробуй `float`, другой keyword или численный `root`/`Find`.
354. Графические: «no real value» — сузь область; пустой график — проверь имена трасс и диапазон.
355. Единичные: «unknown unit» — опечатка или своя единица не определена выше.
356. Программные: «must be boolean» — в If стоит `=` вместо `Ctrl+=`.
357. Матричные: «dimension mismatch» — поэлементное vs матричное; поставь/убери Vectorize.
358. Печатные: обрезанные формулы — убери Fine grid налезания или вставь Page Break выше.
359. Сохранение с ошибками разрешено; при открытии красное останется красным до правки.
360. Для NyaMath: копируем палитру ошибок 1-в-1 (тексты RU/EN), красный цвет результата, блокировку зависимых.

## 20. Поведенческие правила для клона (NyaMath)

432. Холст у нас — бесконечный canvas с абсолютными x/y (как свободное размещение Prime, не потоковый редактор).
433. Порядок вычисления — строго top-to-bottom по `y` (как «сверху вниз» Mathcad); при равном `y` — слева направо по `x`.
434. Регионы: math/text/plot/plot3d/program/slider — маппинг на Math/TextBox/XY/3D/Program Prime.
435. Math-ввод «как на бумаге»: `x := 5`, `f(x) := sin(x)`, trailing `=` для показа; `j` — мнимая единица.
436. Курсор/группировка Prime → у нас построчный редактор кода + LaTeX-превью; Space-группировку эмулируем скобками и предпросмотром.
437. Плейсхолдеры Prime → у нас явные ошибки «незакрытая скобка / пустое выражение» + lenient сообщения RU/EN.
438. Неявное умножение `2π`, `2x` — поддерживаем, как scaling dot Prime; `πθ` без `*` — одно имя (как в Prime!).
439. Деление: `/` — этажная дробь в превью; inline-деление не вводим (избегаем бага солидуса).
440. Единицы: mathjs units (`m/s`, `GHz`, `mm`, `ohm`, `degC`) + `defunit` = custom units Prime.
441. Таблицы Prime 10×10 → у нас матрицы `[1,2;3,4]` + CSV/PNG экспорт графиков.
442. Графики: multi-series `;` = несколько трасс Prime через запятую; polar/bar/stem traces; contour/3D.
443. Plot-регион ссылается на имена, а не хранит копию формулы (как в Prime); данные берутся из scope.
444. Solve Block Prime → у нас `root`/программы + ODE/RK4/RK45/TR-BDF2/FDTD симуляции.
445. Символька `→ simplify/solve/float` → у нас символьные `sym-derivative/sym-integral/simplify` сниппеты.
446. Areas Prime → у нас группировка/undo без потери свёрнутости; disable региона = Diagnosis «исключён из расчёта».
447. Draft-страница Prime → у нас «скрытые» блоки через collapse/hide + share-link без них.
448. Формат результата Prime (General/Engineering/Decimal) → у нас настройка точности + `mean/std` форматирование.
449. Ошибки Prime 1-в-1: undefined, incompatible units, index bounds, recursion, singular — красным + RU/EN тексты.
450. Шрифты: математика — serif/italic для переменных, прямой для функций; единицы — синим жирным (как UniMath + синие units).
451. Активный регион — пунктир; выделенный — тёмная заливка; активный оператор — синий (как в Prime Task 2-2).
452. Перетаскивание региона меняет `y` → меняет порядок вычисления (как в Prime!); подсвечиваем предупреждение при use-before-def.
453. Text Block, толкающий соседей → у нас явный `y`-сдвиг при вставке; Text Box — свободный.
454. Page/Draft виды → у нас View → Live sync + печать/PDF; черновик — через collapse.
455. Горячие клавиши Prime маппим: `:` → `:=`, `Space` → группировка скобками, `Ctrl+T` → text, `[/,` — матрица/таблица.
456. Импорт `.mcdx` не делаем; но JSON проекта + Share-link `#d=` — наш аналог шаблона `.mctx`.
457. Что НЕ копируем: солидус-баг, незнание единиц символькой, хрупкий math-in-text — делаем лучше, документируем отличие.
458. Визуальный эталон для QA: слепки 1–15 из раздела 19 должны быть воспроизводимы в NyaMath построчно.
459. Метрика готовности: новый пользователь Prime выполняет Task 2-2 (правка `19+52` в корень/интеграл/дробь) у нас без обучения.
460. Документация листа — как в блоге PTC: Text + Image + Chart + Header/Footer + Template + PDF.

563. Финал: холст Mathcad — это «бумага, которая считает»; наша задача — та же бумага, но в браузере, без солидус-багов.
564. Mathcad 15 vs Prime: в 15-м белый фон без сетки, в Prime — миллиметровка Standard/Fine; регионы 15-го дрейфуют свободнее, Prime строже к выравниванию.
565. В 15-м math-in-text не было вовсе; в Prime появилось и стало спорным: половина форума любит, половина называет хрупким.
566. Приоритет операторов Prime: скобки → степень/корень → неявное умножение (scaling dot) → явное ×/÷ → +/− → сравнения → логика.
567. Нюанс приоритета: scaling dot по Help равен `*`, но по факту парсер Prime держит его крепче (баг 128278); солидус после него запрещён по ISO 80000-1.
568. Ввод знаменателя: набрал `/` → курсор падает в знаменатель; Space до `/` решает, что уйдёт вниз целиком.
569. Ввод степени: `^` после группы накрывает группу; стрелка вверх входит в показатель, вниз — выходит.
570. Ввод корня: `\` накрывает группу; `Ctrl+\` даёт второй плейсхолдер степени корня слева сверху.
571. Ввод интеграла: `Ctrl+Shift+I` → 4 синих плейсхолдера; Tab идёт низ → верх → тело → переменная; пределы — обычные math-строки.
572. Ввод суммы: `Ctrl+Shift+S` → низ (индекс=старт), верх (конец), справа тело; переменная индекса — literal, не массив.
573. Удаление оператора сохраняет операнды-группы: стер `+` из `a+b` — останутся `a` и `■`/`b`, а не каша.
574. Скобки всегда парные: удаление одной убивает обе; вставка `(` оборачивает группу, а не ставит одну скобку.
575. Матричные скобки `[` растут: `A := [1,2;3,4]` показывает две строки; запятая почти не видна, но решает столбцы.
576. Подписи кривых Prime: первая трасса сплошная синяя, вторая пунктирная красная, третья зелёная с маркерами `o`.
577. Сетка графика: major ticks снаружи, minor внутри; логарифмическая ось показывает `10^n`, а не `1000`.
578. 3D-вращение: drag — orbit, колесо — zoom, правый drag — pan; контурный вид — проекция сверху с изолиниями.
579. Chart Component vs Plot: Chart умеет вторую ось Y и заголовки; обычный Plot — нет; для публикаций берут Chart.
580. Таблица 10×10 максимум: больше — разбивай на две таблицы или матрицу через `augment/stack`.
581. Имя столбца таблицы с пробелом оборачивается в кавычки; без пробела — голое имя-вектор.
582. Единицы столбца в квадратных скобках после имени: `L [m]`; смена единицы в заголовке пересчитывает весь столбец.
583. Диапазон `x := 0,0.1..10`: второе значение задаёт шаг; без него шаг 1; убывающий — `10..0`.
584. Evaluation table из диапазона: слева `x =` даёт столбец входов, справа `f(x) =` — столбец выходов, строки синхронизированы.
585. Guess для Find обязан иметь ту же размерность, что искомое: `x := 50 mm`, а не голое `50`, иначе unit mismatch.
586. Ограничения-неравенства в Solve пишутся `Ctrl+9/Ctrl+0` (`≤/≥`); строгое `<` редко, обычно нестрогое.
587. `Minerr` возвращает ближайшее при несовместной системе; `Find` в том же случае — ошибку; выбор зависит от задачи.
588. `Odesolve` требует производные через оператор `d/dx`, а не через разностные формулы; guess-функция задаёт форму.
589. Программный `for i ∈ 1..10` показывает `∈` как толстую принадлежность; набирается через Matrices/Tables или `Ctrl+Shift+E`.
590. `while` с единицами сравнивает размерные величины: `while x < 5 m` — корректно, `while x < 5` при `x` в метрах — ошибка.
591. Header вмещает ~3 строки: слева лого+компания, центр — имя листа, справа — дата+страница; больше — уже шапка отчёта, не листа.
592. Footer: слева автор+контакты, центр — путь к файлу, справа — `Page N of M`; шрифт на 2 pt меньше основного.
593. Template `.mctx` хранит: units, CTOL/ORIGIN, header/footer, styles, стартовые Text Block + константы проекта.
594. Создание стиля: оформил текст → правый клик → Create Style → имя `NoteBlue` → Edit Style правит всё вхождения разом.
595. Remove Format у математики сносит цвет/highlight/size, но не трогает результат и единицы.
596. Remove Format у текста сносит всё до Normal; новые регионы после глобального Remove идут уже чистые.
597. PDF через Save As сохраняет вектор формул (зум без пикселей); печать через драйвер — растр, формулы мылятся.
598. Прозрачность PNG в Image-регионе сохраняется только через Save As PDF; скриншот листа через буфер — с белым фоном.
599. Невидимка scaling dot видна только при активном регионе; на печати её нет — `2x` выглядит как `2x`, считается как `2·x`.
600. Итоговая метафора из Help: crosshair — «где», blue line — «что правлю», placeholder — «что осталось», Space — «сколько беру», Enter — «посчитай».
